# Dynamic Path Planning using Dijkstra Algorithm

This project simulates a UGV (Unmanned Ground Vehicle) navigating a 20x20 grid using Dijkstra’s Algorithm with dynamic obstacles.

## Features

* Finds shortest path on grid
* Dynamic obstacles added randomly
* Automatic replanning when obstacles appear
* Grid visualization in terminal

## Files

* `main.py` → Python source code

## How to Run

```bash id="z7d2h1"
python main.py
```

## Symbols Used

* `S` → Start
* `G` → Goal
* `U` → UGV Position
* `#` → Obstacle
* `*` → Path
* `.` → Free space

## Requirements

* Python 3.x

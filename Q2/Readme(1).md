# Dijkstra Pathfinding on Grid

This project implements Dijkstra’s Algorithm on a 20x20 grid with randomly generated obstacles.

## Features

* Generates grid with obstacles
* Finds shortest path from Start to Goal
* Displays explored nodes and execution time
* Prints path on grid

## Files

* `main.py` → Python source code

## How to Run

```bash id="i7n4g2"
python main.py
```

Enter obstacle density values such as:

* `0.1`
* `0.2`
* `0.3`

## Symbols Used

* `S` → Start
* `G` → Goal
* `#` → Obstacle
* `*` → Path
* `.` → Free space

## Requirements

* Python 3.x
